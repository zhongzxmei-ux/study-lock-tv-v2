# 学习锁 · 小米电视端（Android TV）编译与部署指南

## 一、内置题库与人教版扩展
- 本工程已内置 **人教版/统编版 一至九年级同步示例题库**（覆盖小学拼音、语文、数学、英语，以及初中语文、数学、英语、物理，含一二年级注音与解题思路）。
- 如需接入海量人教版全章节题库，可将开源项目 `xiaoyang111222/cn-math-taxonomy`（含人教版 1-9 年级数英物理等数千道课标对齐题）或自定义题目按 `questions_sample.json` 格式整理为 `study_lock_questions.json`，放入电视 `/sdcard/Download/` 目录，软件会自动合并加载。

## 二、编译生成 APK
1. 下载并安装 **Android Studio**，打开本目录 `tv_study_lock_android/`。
2. 等待底部 **Gradle Sync** 完成（首次需联网下载依赖）。
3. 顶部菜单点击 **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**，生成 `app/build/outputs/apk/debug/app-debug.apk`。

## 三、小米电视安装步骤（MIUI TV / 澎湃 OS）
### 方式 A：U 盘安装（最简单）
1. 在小米电视 **设置 -> 账号与安全 -> 安装未知来源的应用** 设为 **允许**。
2. 将 `app-debug.apk` 拷入 U 盘根目录，插到电视背面 USB 口，弹出提示后选择「安装包」直接安装。

### 方式 B：ADB 无线安装
1. 打开小米电视 **设置 -> 关于 -> 产品型号**（或版本号）连续按遥控器确认键 5~7 次，开启开发者模式。
2. 返回 **设置 -> 账号与安全 -> ADB 调试** 设为 **允许**。
3. 在电脑终端运行：
   ```bash
   adb connect <小米电视IP>:5555
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```

## 四、小米电视防杀后台与必开权限
1. 打开「学习锁」，点击 **开启守护**，按系统弹窗授予 **「显示在其他应用上层 / 悬浮窗」** 权限。
2. 打开小米电视自带的 **电视管家 -> 应用管理 / 权限管理**：
   - 允许「学习锁」**自启动**；
   - 将后台/省电策略设为 **无限制**，避免切换视频 App 时被 MIUI 内存清理。
